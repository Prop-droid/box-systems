# CCC review — intel — 2026-10-04

TL;DR
- Digest cron dead 12 days: 16/38 Signals items stale + entire Comments tab serving 2026-09-22 intel, zero UI warning
- Silent-failure pattern across 3 tabs: accountItems, SCS join, comments parser all return ok/empty on pipeline error — indistinguishable from quiet week
- Momentum BQ outage handler evicts cache with no cooldown — hammers BQ on every request during an outage
- Competitors WINNER/rank badges go stale 35 min each morning: cache key ignores rank file date
- 86% of VTT top trends are uncorroborated provisional TikTok-only, scoring 88-94 TMS — reads as high-confidence signal
- Comments parser drift will silently zero all sections (questions/ugcQuotes/sentiment) if cron renames a heading

## Findings

1. **[SEV: high]** Digest cron dead 12 days — stale data silently leaks into two tabs — `app/api/research/today/route.ts:47`, `SignalsView.tsx:173`, `app/api/research/digest/route.ts:19` — 16/38 Signals items carry `digestDate: "2026-09-22"`; Comments tab shows "Weekly digest — 2026-09-15 to 2026-09-22" with no staleness indicator; `digest-2026-09-29.md` is absent. Fix: `systemctl --user status comments-digest.timer` to diagnose; add `var(--warn)` badge when `today − digestDate > 8d`.

2. **[SEV: high]** Comments parser silently returns `ok:true` with empty arrays on format drift — `lib/commentsDigest.ts:142-144` — `sec()` returns `''` on heading regex miss; DigestSection hides with no error; no `partial:true` or `emptyFields:[]` field. Fix: return `{ ok:true, partial:true, emptyFields:['questions',...] }` when tldr+themes are empty.

3. **[SEV: high]** Signals `accountItems`/`winnerItems` fail silently — BQ outage and quiet week are indistinguishable — `route.ts:129-203` — 0/38 account-delta or new-winner items live; exceptions caught and swallowed; no `sourceErrors` field. Fix: add `sourceErrors: { source, error }[]` to response; render degraded-data banner in SignalsView when non-empty.

4. **[SEV: high]** Momentum `DegradedFill` evicts cache with no cooldown — hammers BQ during outages — `route.ts:122-131`, `lib/cache.ts:14` — On `DegradedFill`, cache key deleted and re-throws; every subsequent request retries BQ immediately. Fix: cache the degraded payload under a 5-min TTL and return it.

5. **[SEV: med]** Competitors cache key omits rank file date — WINNER/rank badges stale ~35 min each morning — `app/api/swipe/atria/route.ts:56` — Swipe lands 01:46, rank at 02:21; first request in that gap caches without today's rank. Fix: `swipe:atria:${newest.file}:${rankDate}`.

6. **[SEV: med]** Competitors SCS join failure has no UI indicator — grid silently loses all evidence chips — `route.ts:60-82` — Entire enrichment block in `try/catch`; no `enriched` boolean in response. Fix: add `{ enriched: boolean }`, render "SCS data unavailable" footer when false.

7. **[SEV: med]** VTT provisional TMS uncapped — 86% of top trends score 88-94 from a single TikTok source — `lib/vtt.ts:158` — Provisional boost ÷0.70 ≈ +43%; BREAKOUT chip is gated but the raw TMS number reads as near-certainty. Fix: cap provisional TMS at 70 or visually distinguish provisional from corroborated score.

8. **[SEV: med]** VTT staleness dead zone — single-night lane failure invisible for 24-48h — `lib/vttServer.ts:99-111` — Threshold `>= 2 days`; TikTok had 23 consecutive empty files with no stale warning the first night. Fix: lower to `>= 1.5` (36 h) for non-retail lanes.

9. **[SEV: med]** Comments `/api/research/digest/route.ts` has no try/catch — fs error propagates as unstructured 500, violating house convention — Fix: wrap in try/catch, return `{ error: string }` with real status.

10. **[SEV: med]** Momentum rising-angle fires on single week, no brand guard — `lib/trending.ts:81` — `priorTotal===0 && last>=3` flags angles with zero history; live: `usp_efficacy` [0,0,0,19] and `outcome` [0,0,0,6] both RISING from one brand. Fix: require `last >= 5 && brands >= 2`.

11. **[SEV: med]** Momentum `tagMomentum` silently returns `[]` when tagging data lags; `tagsAvailable` stays `true` — `lib/trending.ts:327` — Fix: return `tagsStale: true` when latest tag week is >10 d old.

12. **[SEV: med]** Comments date-filter label says "comment-creation date" but SQL filters on scrape date — `lib/commentsQueries.ts:38,63` — Fix: correct label to "scrape date range."

13. **[SEV: med]** Signals `feedCutoff` midnight-rounded — items up to 71 h old pass the 48 h guard — `route.ts:234` — `slice(0,10)` gives date string; `"2026-10-02T00:00:01Z" >= "2026-10-02"` is true all day. Fix: compare full ISO strings.

14. **[SEV: med]** Momentum `computeEmergence` gap-angle signal never surfaces in Momentum tab — `lib/competitorPatterns.ts:71-136` — Strongest competitor signal only wires into `/api/research/today`. Fix: include `emergenceAlerts` key in `/api/research/trending` response.

15. **[SEV: low]** Competitors WINNER badge fires on any rank position, not top half — `lib/scs.ts:126` — `!!rank` truthy for bottom-of-list; 5 of 18 live WINNERs have `rank > 10`. Fix: gate on `rank <= ceil(total * 0.5)`.

16. **[SEV: low]** Competitors `rank.total` stripped from serialized badge — `route.ts:75-80` — `#11 of 12` and `#11 of 60` render identically. Fix: pass `rankTotal` through; render `#rank/rankTotal`.

17. **[SEV: low]** Competitors lane chips with 0 advertisers clickable, silently empty grid — `CompetitorsView.tsx:38-44` — "9pm cravings" and "GLP-1 fiber gap" live with `advertisers:0`. Fix: dim and disable.

18. **[SEV: low]** Comments `postCommentsSql` raw-interpolates `postId` — `lib/commentsQueries.ts:52` — No regex guard; safety depends on calling route. Fix: add `\d+_\d+` guard matching the existing `shFilter` pattern.

19. **[SEV: low]** Signals `invalidate` fires before 8-second undo window — `SignalsView.tsx:92` — Burns a re-fetch during undo. Fix: move inside the `setTimeout` callback.

20. **[SEV: low]** Signals "1 advertisers" grammar — `route.ts:121` — Fix: `advertiser${count === 1 ? '' : 's'}`.

## Verdict

All five live endpoints returned data; four of five were fresh within 24 h; VTT and Competitors pipelines ran overnight as expected. The critical gap is the broken digest cron (12 days silent) compounded by a systemic pattern where four aggregating routes return `ok: true` or empty arrays on pipeline failures, making every empty state ambiguous. The single highest-value fix is the cross-cutting one: add a `sourceErrors` / `partial` / `enriched` / `tagsStale` signal to each aggregating route so the UI can show a degraded-data banner instead of silently serving incomplete intel.
