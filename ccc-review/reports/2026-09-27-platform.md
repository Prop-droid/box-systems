# CCC review — platform — 2026-09-27

TL;DR
- Cache key split (`research:digest` vs `research:digest:latest`) means Signals and Digest tabs show different digest for up to 5 min after cron
- Backtest-summary parse failure silently returns `ok:true, summary:null` — broken is indistinguishable from "never ran"
- Sunday users see current week disappear from the week picker all day (lib/weeks.ts off-by-one)
- Two RESEARCH_DIR feeds (mechanisms, research feed) have no cron-status coverage — timer failure is invisible
- Three report/feed routes return 200+empty on misconfiguration — looks identical to "nothing yet"
- CLAUDE.md data-source table missing 3 actively-queried BQ tables (CRO, TAG_VIDEO, TAG_STATIC)

## Verdict

Shell and nav are clean — all deep links resolve, legacy redirects are correct, Tailscale gate is sound. The platform's sharpest pain is in the API layer: the `research:digest` cache key split causes live data divergence between Signals and Digest tabs on every cron cycle, and three routes (report, feed, backtest-summary) are indistinguishable from healthy when misconfigured or broken. Highest-value single fix: standardize both digest cache keys to `'research:digest:latest'` — one-line change, eliminates the most user-visible correctness bug.
