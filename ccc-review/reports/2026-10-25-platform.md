# CCC review — platform — 2026-10-25

TL;DR
- Middleware missing `cron-status` in PUBLIC_PREFIXES — ts.net users see "checking crons…" forever (false-green shell)
- Middleware has no `matcher` config — runs on every `_next/static` asset; any new API route silently 404s for ts.net clients
- `research/today` digest+feed failures drop silently with no sourceErrors entry — operator sees fewer signals but no alert
- `report/latest` returns HTTP 200 with empty markdown on FS read error — broken pipeline looks identical to empty report
- `logDecision` POST skips `invalidate('/api/overrides')` — SystemHealth shows stale decisions for up to 10 min after any action
- comments-digest mtime predates its timer by 50 min — if manual producer stops, weekly timer is silent for up to 8 days

## Findings

[SEV: high] `/api/cron-status` not in PUBLIC_PREFIXES — `middleware.ts:7-13` — ts.net public clients hit a 404 on every cron-status fetch; TopNav shows "checking crons…" indefinitely — add `'/api/cron-status'` to `PUBLIC_PREFIXES`

[SEV: high] Middleware missing `config.matcher` export — `middleware.ts` (whole file) — runs on every `/_next/static/*` and `/_next/image/*` request; any new API route a ts.net client calls silently 404s if not in PUBLIC_PREFIXES — add `export const config = { matcher: '/((?!_next/static|_next/image|favicon.ico).*)' }`

[SEV: med] Digest + feed failures invisible in `sourceErrors` — `app/api/research/today/route.ts:232-233` — `latestDigest` and `readFeedItems` return null/[] on failure without a `soft()` wrapper; silently drops cards with no pipeline-failure flag — wrap both in `soft('digest', ...)` and `soft('feed', ...)`

[SEV: med] FS read error on report returns HTTP 200 with empty markdown — `app/api/report/latest/route.ts:254` — catch returns `{ week: null, markdown: '', weeks }` + 200; operator can't distinguish "genuinely empty" from "Drive mount dropped" — return `{ error: '...', weeks }` + 500

[SEV: med] `logDecision` POST missing `invalidate('/api/overrides')` — `app/components/ActionButton.tsx:36` — SystemHealth stale for 10 min after every action button click — add `invalidate('/api/overrides')` in the fetch `.then()`

[SEV: med] comments-digest mtime predates timer by 50 min — `app/api/cron-status/route.ts:35` — Oct 20 files written 04:07 EEST, timer fired 05:00 EEST; if manual pre-runner disappears the weekly timer is silent for up to 8 days — add INVOCATION_ID guard in digest script or lower `maxAgeHours` to 216 + add timer-run-age check

[SEV: med] Mac-era config defaults still in `lib/config.ts:12-13` — `feedbackDir`/`memoryDir` point to Mac paths; wrong on box without `.env.local` — update defaults or add startup assertions (documented but unfixed)

[SEV: low] Intel deep-link flash: localStorage mode overrides URL `?mode=` param on first render — `app/intel/page.tsx:50-54` — single-frame mode switch — pre-compute initial value as `coerceMode(modeParam ?? null)` when `modeParam != null`

[SEV: low] CronStatus inline time is UTC, not local — `app/components/TopNav.tsx:39` — displayed 3h behind Europe/Vilnius — use `new Date(newest).toLocaleTimeString([])`

[SEV: low] `/research?mode=today` routes through invalid intermediate `?mode=lanes` — `app/research/page.tsx:7` — `lanes` is not a valid Intel mode; resolves correctly via second legacy map but creates a bookmark-able misleading URL — map directly to `'competitors'` in `LEGACY_MODE`

[SEV: low] `research/feed` route has no try/catch — `app/api/research/feed/route.ts:8` — unhandled 500 on unexpected error; all peers use `errorResponse(e)` — wrap in try/catch

[SEV: low] `backtest-summary` swallows corrupt JSON as `{ ok: true, summary: null }` — `app/api/backtest-summary/route.ts:64` — indistinguishable from "never run" — return `{ ok: false, error: 'corrupt' }` from parse catch
