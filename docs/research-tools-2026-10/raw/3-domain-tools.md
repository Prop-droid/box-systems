# Domain research tools, Oct 2026 (slice 3): ad intel, customer voice, trends, claims verification, MCP bundles

Researched 2026-10-06 for Shameless Snacks (Meta DTC, TikTok Shop, Amazon). Judged on: can a headless agent call it (REST/MCP), price, and incremental value over what the box already has.

Confidence tags: [P] = primary/vendor page fetched this session; [S] = secondary (vendor blog, aggregator, comparison site; may be biased or stale); [U] = unverified / could not confirm. Prices are as quoted on the cited page on 2026-10-06 unless noted.

## 0. What the box already has (so we do not re-buy it)

Source: local memory + `~/systems/viral-trend-tracker/` (read 2026-10-06).
- Atria REST API wired (`api.tryatria.com/open/v1`, X-API-Key, key expires ~monthly). Atria also advertises an MCP server (see A4).
- Cruva MCP (TikTok Shop creators, products, videos, slideshows, lives, GMV Max creatives, own Meta ads). This covers most of what Kalodata/FastMoss sell.
- Apify MCP + Apify token. VTT notes the nightly Amazon actor (~$0.40/run) exhausted the $5 free-tier credit mid-cycle and 403'd the TikTok lane, so the box is on Apify FREE tier. Starter is $19/mo (https://apify.com/pricing) [P].
- CLIs: `amz` (only `search` and `pdp` subcommands, no reviews), `rdt` (cookie-based Reddit), `tw` (X), `yt-dlp` (supports `--write-comments`, verified locally via `yt-dlp --help`).
- VTT lanes: reddit (rdt), x (tw), youtube (yt-dlp flat search; YouTube Data API was 403/disabled on the box GCP project), ads (Atria variant counts), tiktok (Apify data_xplorer/tiktok-trends = Creative Center hashtags, F&B + Health), trends (Google Trends "Trending Now" RSS only, NOT interest-over-time for the watchlist), amazon (Best Sellers, monthly).
- Gaps confirmed on the box: no Amazon review text, no TikTok comments, no Google Trends time series for watchlist terms, no claims/literature tooling wired.

## G. Gaps nobody fills well

- Amazon review VERBATIMS at scale: public view is ~8 reviews per product, full histories need logged-in scraping (ToS/fragile); SP-API gives topic aggregates only.
- Competitor ad performance (spend, ROAS, true CTR, conversion): nobody; only run duration, variant count, TikTok's normalized CTR rank.
- Compliant, scalable Reddit: official commercial access is approval-gated (2-4 weeks) and priced per call (unverified); GummySearch died on exactly this; Arctic Shift has no SLA and no global full-text search; our `rdt` is cookie-based and brittle.
- TikTok comments and competitor Meta ad comments: official TikTok Research API excludes commercial users; competitor ad comments have no source at all.
- Leading-indicator trend APIs: Google Trends official API is alpha; Pinterest Trends is gated and today-only; Glimpse API is quote-only; Exploding Topics API starts at $1,000/mo and cannot look up custom keywords.
- Claim -> evidence -> regulatory-risk mapping: tools find papers and citation stance, but nothing returns "is this claim substantiated to FTC standard / likely NAD challenge"; NAD/CRN database and FTC guidance have no API. This stays an in-house skill (we already have compliance-scrub plus the compliance eval harness).
- Research -> brief handoff: Foreplay Briefs, Gethookd clone ads and Atria image generation exist, but none know Shameless canon; Magic Brief is gone. Stays in-house.
